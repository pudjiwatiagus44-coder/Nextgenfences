NextGenFences v1.0 - 桌面整理工具
=====================================

功能特点:
- 创建多个Fence分区来整理桌面图标
- 支持拖拽排序
- 支持自定义透明度和视图模式
- 悬浮球快速访问

使用方法:
1. 双击 NextGenFences.exe 启动程序
2. 点击悬浮球创建新的Fence
3. 将文件/文件夹拖入Fence中整理
4. 右键Fence可设置透明度、视图模式等

快捷键:
- Win+D: 显示桌面（Fence会保持显示）

系统要求:
- Windows 10/11
- 无需安装，直接运行
